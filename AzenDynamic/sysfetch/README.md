# sysfetch
sysfetch is a terminal tools to show the system info and custom ascii logo

## install
install the whole folder to your path
example ~/Desktop
## run
cd ~/Desktop/sysfetch 
chmod +x sysfetch.py
./sysfetch.py

## requirment
python 3.12 +
