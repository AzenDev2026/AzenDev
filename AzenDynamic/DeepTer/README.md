# DeppTerminal / DeepTer（旧版归档）

> ⚠️ 本目录是 **DeepTerminal** 的旧版代码（早期叫 Wtml / Winzer Terminal / DeppTerminal），已停止在此维护，内容不代表最新版本。

一个基于 Qt 的 Linux 终端模拟器：在真实 PTY 上运行 PowerShell 7 / Bash 等任意 shell，支持标签页、滚动回看、搜索、鼠标上报、IME 输入、主题和自定义彩色提示符。
