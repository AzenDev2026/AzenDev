# Azen Dynamic  <img width="50" height="50" alt="office_blue_gradient" src="https://github.com/user-attachments/assets/600198a5-e274-454f-82bb-3d2c595635a0" />

**Azen Dynamic** is the software ecosystem branch of the Azen
project: system-level tools and technologies that improve performance,
battery life and usability on Linux laptops.

> ⚠️ **This directory is now a legacy archive.**
>
> Every project folder in this directory contains **legacy code** and is no longer maintained here. Each major project now has its own dedicated repository — please get the latest code from the corresponding repository in the table below.

## Legacy projects → new repositories

| Legacy folder in this directory | Description | New repository (latest) |
|---|---|---|
| `freeze-manager` | Legacy component of the NAAP technology (App Nap: freeze on minimize / thaw on focus) | [NAAP](https://github.com/AzenDev2026/NAAP) |
| `alrm4` | ALRM 4 resource management (superseded by NAAP) | [NAAP](https://github.com/AzenDev2026/NAAP) (successor) |
| `alprm(test)` | ALPRM sleep stack prototype (superseded by NAAP) | [NAAP](https://github.com/AzenDev2026/NAAP) (successor) |
| `DeepTer` | Legacy terminal tools (Wtml / DeppTerminal) | [DeepTerminal](https://github.com/AzenDev2026/DeepTerminal) |
| `kde-setting-shell` | Legacy KDE system settings replacement shell | [NVazenSettings](https://github.com/AzenDev2026/NVazenSettings) |
| `sysfetch` | Legacy system info + ASCII logo terminal tool | [sysfetch](https://github.com/AzenDev2026/sysfetch) |

The remaining items (`AlreSearch`, `SmallProject`, `sysver`, etc.) are early small projects / examples with no dedicated repository yet.
