# Azen Dynamic（Azen 灵动）  <img width="50" height="50" alt="office_blue_gradient" src="https://github.com/user-attachments/assets/600198a5-e274-454f-82bb-3d2c595635a0" />

**Azen Dynamic（Azen 灵动）** is the software ecosystem branch of the Azen
project: system-level tools and technologies that improve performance,
battery life and usability on Linux laptops.

> ⚠️ **本目录现为旧版归档（legacy archive）。**
>
> 目录内各项目文件夹均为**旧版代码**，已停止在此维护。每个主要项目现在都拥有自己的独立仓库，最新代码请前往下表对应仓库获取。

## 旧版项目 → 新仓库

| 本目录旧版文件夹 | 简介 | 新仓库（最新版） |
|---|---|---|
| `freeze-manager` | NAAP 技术（App Nap：最小化冻结 / 聚焦解冻）旧版组件 | [NAAP](https://github.com/AzenDev2026/NAAP) |
| `alrm4` | ALRM 4 资源管理（已被 NAAP 取代） | [NAAP](https://github.com/AzenDev2026/NAAP)（后继） |
| `alprm(test)` | ALPRM 睡眠栈原型（已被 NAAP 取代） | [NAAP](https://github.com/AzenDev2026/NAAP)（后继） |
| `DeepTer` | 终端工具旧版（Wtml / DeppTerminal） | [DeepTerminal](https://github.com/AzenDev2026/DeepTerminal) |
| `kde-setting-shell` | KDE 系统设置替代外壳旧版 | [NVazenSettings](https://github.com/AzenDev2026/NVazenSettings) |
| `sysfetch` | 系统信息 + ASCII logo 终端工具旧版 | [sysfetch](https://github.com/AzenDev2026/sysfetch) |

其余内容（`AlreSearch`、`SmallProject`、`sysver` 等）为早期小项目 / 示例，暂无独立仓库。
